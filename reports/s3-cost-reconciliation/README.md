# ② scan費用を全反復分計上した収支と見積もり確定条件

2026-10-28 JST。これまでの98%台は、U0=20Mcycle/sに基礎25000反復/s分のscan費用が収まるという未検証の前提を残していた。新たに数えた通常経路を平均費用と仮定するなら、この前提は両立しない。

## 収支の修正

旧模型は `固定費用 + U0 + (反復頻度−25000)*scan費用`。U0全額をscanに使っても20000000/25000＝800cycle/反復であり、他の費用を含めればそれ未満になる。指定経路1729.2/1767.7cycleは平均ではないが、この値を平均と仮定する感度計算でU0を20Mのままにすると、基礎25000反復/s側を23.230/24.1925Mcycle/s過小計上する。

新しい収支は `packing＋fill＋転送API＋準備管理予約＋全反復scan＋その他残余`。U0と差分scanを一旦両方除去し、全反復へscanを課金する。その他残余Rは未確認で、下表のR=0は計算条件である。実際にゼロと判断したわけではない。α=1.1、転送API20µs、管理200cycle/反復は従来と同じ。

| S core0 | 512pair | 256pair |
|---|---:|---:|
| scan・残余以外の占有率上端 | 83.9391% | 88.8696% |
| 平均scan1729.2cycle、R=0 | **107.9557%** | **112.8863%** |
| 平均scan1767.7cycle、R=0 | **108.4905%** | **113.4210%** |
| R=0で100%境界となる平均scan上限 | **1156.386cycle** | **801.386cycle** |

したがって、指定通常経路を平均に置いた同条件では512もCPU超過になる。以前の98.28〜98.41%を同条件の全費用込み結果として使わない。実際の状態頻度をまだ求めていないため、この表を実測値・全実装の不成立証明にも使わない。512の平均scan予算はRが1Mcycle/s増えるごとに30cycle/反復減る（33333.33反復/s時）。

全ケースについて `新結果−旧差分scan結果 = (25000*scan−20000000)/2400000` を検算した。再現：`python -m experiments.s3_cost_reconciliation`。結果はresults.json。

## 「見積もり確定」の完了条件

確定対象は、構成・前提・適用範囲・未保証事項を固定した条件付き設計見積もり。ハードウェアでの成立確認とは別である。単一の命令cycle係数を都合よく置くだけでは成立見積もりの確定にはしない。

| 残項目 | この環境で行う作業 | 見積もりの完了条件 |
|---|---|---|
| SoCの全費用収支 | owner/workerの通常・空振り・準備・切替・settling・公開・SPI完了/submit・watchdog更新・IRQを列挙。各関数/費用を一つの費用区分に割り当て、各状態の到来回数を入力流量と実runtimeから導く | 未計上を残余Rの明示範囲として残し、二重計上0。平均費用の算出根拠、命令→cycleの仮定と必要な残余予算を提示。合否が未確定範囲で変わるなら条件付き境界として結論を固定する |
| 期限・転送・buffer | 同じ処理費用と非一様な順序でowner/worker/SPIを時系列評価。公開/reclaim/準備/RF監視gap・2port帯域を同時評価 | 宣言した入力・割込み・待ち時間範囲に対しdeadlineと128KiB容量を満たす/満たさないを示す。一定scan30µsの別模型だけでは完了にしない |
| FPGA全段 | RF endpoint、復調各段、memory、T/S独立TSまで接続した同一topで合成・配置配線 | 同一topの資源上限と必要clockの両方を満たす/満たさないを報告。部分166.22MHzを流用しない。未実装段を台帳の仮値で隠さない |
| 最終採否 | 上記結果を同じ構成/commitへ揃え、候補台帳と経路表を更新 | ユーザー指定の性能評価→通信路割当→経路非空の採用を実施。成立・不成立・条件付きのどれかを根拠と共に確定 |

実機が必要なのは、RF連続取得と品質、MMIO/DMA/IRQ競合下の実経過時間、実heap/起動、T/S同時TSの裏付け。これを待たずに計算可能な見積もりを進める一方、実測なしで無条件のハードウェア成立は保証しない。

次に進める順序はSoC全費用収支→同じ費用で期限とbuffer→全段FPGA→採否。FPGA側の独立作業はこの順序に依存せず進められる。①は変更しない。
